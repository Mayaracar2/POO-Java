# Programação Orientada a Objetos (POO)

Este repositório reúne todas as atividades desenvolvidas em sala de aula durante a disciplina de Programação Orientada a Objetos (POO), contendo exercícios práticos, implementações em Java e materiais utilizados ao longo do semestre.

## Conteúdo do repositório

* Exercícios desenvolvidos em sala de aula;
* Práticas de programação utilizando Java;
* Exemplos e aplicações dos conceitos de POO;
* Materiais e arquivos de apoio utilizados durante a disciplina.

## Conceitos abordados

Ao longo das atividades foram trabalhados os principais fundamentos da Programação Orientada a Objetos, incluindo:

* Classes e Objetos;
* Encapsulamento;
* Herança;
* Polimorfismo;
* Abstração;
* Construtores;
* Métodos e atributos;
* Modificadores de acesso;
* Relacionamento entre classes;
* Organização de projetos orientados a objetos.

O objetivo deste repositório é centralizar os conteúdos desenvolvidos durante a disciplina, servindo como apoio para estudos, revisão dos conceitos e acompanhamento da evolução prática em Programação Orientada a Objetos.
